# 板橋房產監控中心

GitHub Pages 房產案件監控前端，主要用途是追蹤指定板橋社區的目前出售案件、跨平台同案整合、每日價格／狀態變化，以及房仲開發案件。

## 目前監控的 13 個社區

板橋新巨蛋、板橋文化勳章、板橋公園世紀、欣璞綻、綠如意、鑑築、榮耀交響曲、佳元植、板橋千禧園、板橋吉祥花園、雙喜臨門、板橋晴、永康芬揚。

## 資料規則

- 來源包含 591、信義、樂屋、樂居、永慶、中信、住商、台灣房屋、好房網；能取得的直接案件頁才視為逐案核實證據。
- 社區頁或搜尋頁顯示的「在售筆數」只是平台聚合數，不等於網站已逐案核實的案件數。
- 來源有樓層時必須顯示樓層；無法確認時顯示「樓層待確認」，不得猜測。
- 取得有效原始案件直連時必須提供；社區首頁、搜尋頁、分類頁不能冒充案件直連。
- 直接案件網址會定期健康檢查；403／429／timeout 等存取限制不能直接判定售出，404／410 或明確下架訊息才可進入下架判定流程。
- 同樓層、同坪數、同格局不足以證明是同一戶；必須優先依平台物件編號、直接網址、地址／戶別、照片／格局圖、groupId 或共享平台證據去重。
- 歷史實價登錄成交資料不列為目前在售案件。
- 無法完成全平台逐案核實時，網站必須標示「🟡部分完成」，不得宣稱 100% 完整。

## 網站功能

1. 全部案件：社區、棟別、樓層、價格、坪數、格局、車位與排序篩選。
2. 每日市場變化：新增、降價、漲價、消失／下架／狀態變更。
3. 開發案件：只保留已確認永慶未刊登的在售案件；永慶已刊登者不列入競業開發清單。
4. 同案平台整合：同一物件可在同一張卡片顯示多個來源平台與原始連結。
5. 13 社區快速選單：可直接切換社區篩選。

## 自動更新

GitHub Actions 每 3 小時執行一次公開來源掃描與已知案件網址驗證。掃描遇到來源封鎖時不會把空結果直接覆蓋既有資料。

## 重要限制

目前資料仍以可公開取得且可直接驗證的內容為準。部分平台會使用反爬、登入或動態載入，因此「平台顯示筆數」與「逐案核實筆數」可能不同。網站會保留待確認狀態，而不是用猜測補齊。

## GitHub Pages

Repository → Settings → Pages → Build and deployment 選擇 **Deploy from a branch**，Branch 選 `main` / `/ (root)` 後儲存即可發布。
